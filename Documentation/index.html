🚀 2. Quick Local Launch

Arun AI comes with an executable JAR pre-built with Spring Boot 3 and Java 21.

Windows: Double click start.bat

Linux / macOS: Run the terminal command:

chmod +x start.sh && ./start.sh

Access the interface at: http://localhost:8080/

🐳 3. Docker Deployment

To run with Docker on any VPS:

docker-compose up -d --build

The container starts automatically on reboot and exposes port 8080.

💰 4. Changing Payment Gateways to Your Own Account

To receive 100% of the payments directly into your bank account:

  • PhonePe UPI: Open src/main/resources/templates/index.html, search for 9014218406@ybl, and replace it with your own UPI ID. Replace the QR image in src/main/resources/static/images/arun_phonepe_qr.jpg with your own QR code.
  • Razorpay: Set your Razorpay Key ID in index.html inside the payWithRazorpay() function.

📱 5. Publishing to Free App Stores

Amazon Appstore (100% Free):

  • Sign up at developer.amazon.com.
  • Click Add New App ➔ Web App.
  • Enter your HTTPS hosted website URL, upload the included icon-512.png, and submit for free review!
